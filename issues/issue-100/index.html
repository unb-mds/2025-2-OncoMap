[FEATURE]Atualizar o git pages para a release 2

🎯 Descrição

Atualizar o conteúdo do GitHub Pages (site de documentação/demonstração) do projeto para refletir as novidades, documentação e status da Release 2.

✅ Objetivo

O GitHub Pages precisa estar sincronizado com a versão mais recente do projeto (Release 2). Essa feature é importante para:

  • Informar os usuários: Garantir que a documentação, tutoriais e exemplos no site estejam corretos e correspondam à funcionalidade da Release 2.
  • Manter a credibilidade: Evitar que os usuários utilizem documentação desatualizada, prevenindo confusão e erros.

📝 Detalhes da Implementação

  • Atualizar o Branch de Publicação: Garantir que o branch configurado para publicar o Pages (geralmente gh-pages ou main/master com a pasta /docs) esteja com os arquivos de documentação mais recentes.
  • Revisão de Conteúdo:
    • Atualizar a página inicial/landing page para mencionar a Release 2 como a versão estável/atual.
    • Revisar e corrigir tutoriais, guias de instalação e exemplos de código para garantir que sejam compatíveis com a Release 2.
  • Verificação de Links:
    • Confirmar que todos os links para downloads, repositórios ou recursos externos estão funcionando e apontam para a Release 2 (se aplicável).

📊 Critérios de Aceitação

Quais pontos devem estar presentes para considerar a feature concluída?

  • O site do GitHub Pages está online e acessível.
  • Todos os tutoriais e exemplos foram revisados e estão corretos para a Release 2.
  • O código-fonte dos exemplos no site, se houver, está sincronizado com a Release 2.
  • Nenhum link está quebrado ou aponta para uma versão antiga do projeto.
