[TASK] - Novo guia de contribuição e conduta

Docs: Adicionar Guia de Contribuição (CONTRIBUTING) e Código de Conduta

🎯 Descrição

Para tornar o projeto OncoMap mais acessível para novos desenvolvedores e garantir um padrão de qualidade e convivência na comunidade, precisamos adicionar arquivos de documentação essenciais na raiz do repositório.

O objetivo é orientar claramente como configurar o ambiente, como rodar o projeto (Backend/Frontend) e quais padrões de commit seguir.

✅ Objetivos

  1. Criar o arquivo CONTRIBUTING.md com instruções técnicas de setup e padrões de projeto.
  2. Criar o arquivo CODE_OF_CONDUCT.md para estabelecer as normas da comunidade.

📝 Tarefas (To-Do)

  • Criar CONTRIBUTING.md na raiz:

    • Adicionar pré-requisitos (Git, Node v20+, Supabase, Docker).
    • Incluir comando específico para Linux: sudo apt install docker-compose.
    • Documentar instalação do Monorepo (npm install na raiz).
    • Explicar como rodar Backend e Frontend individualmente e via concurrently.
    • Importante: Adicionar seção sobre Conventional Commits e reforçar a necessidade de commits claros e semânticos.

  • Criar CODE_OF_CONDUCT.md na raiz:

    • Adicionar texto padrão (Contributor Covenant) para garantir um ambiente inclusivo.

📊 Critérios de Aceitação

  • O arquivo CONTRIBUTING.md existe na raiz e está bem formatado em Markdown.
  • As instruções de instalação foram testadas e funcionam para um novo desenvolvedor.
  • O arquivo CODE_OF_CONDUCT.md existe na raiz.
  • Os arquivos foram adicionados ao git com um commit seguindo o padrão docs: ....
