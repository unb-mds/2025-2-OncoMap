[TASK] - Definir metodo de tratamento dos dados

🎯 Objetivo / Motivação

Testar e validar dois métodos distintos para o tratamento (extração/processamento) de dados provenientes de arquivos PDF. O objetivo é comparar a eficácia, precisão e performance de cada método para selecionar a melhor abordagem para o projeto, garantindo que a solução escolhida seja a mais robusta e eficiente.

📋 Escopo da Tarefa e Entregáveis

Liste de forma clara e detalhada as atividades que precisam ser executadas. O que deve ser entregue ao final desta tarefa?

  • Selecionar um conjunto representativo de PDFs (amostras) para servirem de base para os testes.
  • Implementar um script ou protótipo para o Método A que processe as amostras.
  • Implementar um script ou protótipo para o Método B que processe as amostras.
  • Definir as métricas de comparação (ex: precisão da extração, tempo de processamento, facilidade de implementação, robustez a layouts diferentes).
  • Executar ambos os métodos e coletar os dados comparativos.

✅ Critérios de Aceitação

Como saberemos que a tarefa foi concluída com sucesso? Liste os pontos que devem ser validados.

  • Os testes foram realizados no mesmo conjunto de PDFs de amostra para uma comparação justa.
  • O relatório comparativo está completo, detalhando as métricas coletadas para ambos os métodos.
  • Uma recomendação clara sobre qual método adotar (e por quê) foi fornecida com base nos resultados.
  • A equipe revisou os resultados e concordou com a recomendação.
  • Foi definido um metodo mais eficaz
