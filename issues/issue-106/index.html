[Design] Atualização do Figma para Paridade com a Implementação

📝 Descrição / Objetivo

Atualizar o protótipo de alta fidelidade no Figma para refletir o estado atual do projeto desenvolvido.

Comportamento Atual: O arquivo do Figma está desatualizado e apresenta inconsistências visuais e de fluxo em relação ao código que já está em produção/desenvolvimento. Comportamento Esperado: O Figma deve espelhar exatamente a versão implementada (cores, espaçamentos, componentes e fluxos), servindo novamente como fonte da verdade para futuras iterações.

✅ Tarefas

  • Atualizar a biblioteca de componentes (botões, inputs, cards) para bater com o CSS atual.
  • Ajustar layouts de telas que sofreram alterações durante o desenvolvimento.
  • Remover telas ou fluxos que foram descartados na implementação.
  • Adicionar prints do sistema atual no Figma para referência (opcional, mas recomendado).

📌 Critérios de Aceitação

  • Paridade Visual: As telas principais do Figma estão idênticas visualmente ao ambiente de desenvolvimento.
  • Design System: As variáveis de cores e tipografia no Figma correspondem ao código.
  • Componentes: Novos componentes criados diretamente no código agora existem no Figma.
  • Fácil entendimento: Qualquer membro do grupo consegue consultar o Figma e entender o funcionamento atual do site.
